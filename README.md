# 🎬 YT Downloader PRO

> Descarga videos de YouTube 100% gratis — en cualquier calidad, con recorte de fragmentos y extracción de audio.

![Python](https://img.shields.io/badge/Python-3.8+-3776AB?style=for-the-badge&logo=python&logoColor=white)
![yt-dlp](https://img.shields.io/badge/yt--dlp-Latest-FF0000?style=for-the-badge&logo=youtube&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-00D4AA?style=for-the-badge)

## ✨ Funcionalidades

- 🎥 **Múltiples calidades**: Mejor calidad, 1080p, 720p, 480p
- 🎵 **Extracción de audio**: Solo audio en MP3 a 192kbps
- ✂️ **Recorte de fragmentos**: Descarga solo la parte que necesitas
- ⚡ **Velocidad máxima**: Sin throttling ni límites
- 🆓 **100% Gratis**: Sin pagos, sin suscripciones, sin anuncios
- 🔓 **Open Source**: Código fuente disponible para todos

## 🚀 Instalación

### Requisitos previos

- [Python 3.8+](https://www.python.org/downloads/)
- [FFmpeg](https://ffmpeg.org/download.html) (necesario para combinar video y audio)

### Pasos

1. **Clona el repositorio:**
```bash
git clone https://github.com/tu-usuario/youtube-downloader.git
cd youtube-downloader
```

2. **Instala las dependencias:**
```bash
pip install yt-dlp
```

3. **Ejecuta el script:**
```bash
python descargar_video.py
```

## 📖 Uso

1. Ejecuta el script de Python
2. Pega la URL del video de YouTube
3. Elige la calidad deseada (1-5)
4. Opcionalmente, recorta un fragmento indicando inicio y fin
5. ¡Espera a que se descargue!

### Ejemplo

```
Pega la URL del video de YouTube: https://www.youtube.com/watch?v=dQw4w9WgXcQ

Elige la calidad:
1. Mejor calidad disponible (sin pérdida)
2. 1080p
3. 720p
4. 480p
5. Solo audio (mp3)
Opción (1-5): 2

¿Quieres descargar solo una parte del video?
1. Sí, indicar inicio y fin
2. No, descargar todo
Opción (1-2): 2

Descargando...
✅ ¡Descarga completada!
```
